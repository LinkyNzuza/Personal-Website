# Linky Nzuza – Portfolio Website

A personal portfolio website built with HTML, CSS, and JavaScript. No frameworks, just vanilla web development.

---

## Pages

- **Home** – Landing page with a short intro and hero image
- **About** – Three-column layout with image cards on the sides and text in the center
- **Projects** – Each project is a card that slides to reveal more detail
- **Game Blogs** – Sidebar with game genres, clicking one loads the blog post on the right
- **Contact** – Links to email, GitHub, LinkedIn, and a CV download

---

## Folder Structure

```
portfolio/
├── index.html
├── about.html
├── projects.html
├── gameblogs.html
├── contact.html
├── CSS/           # style.css (one file for all pages)
├── JS/            # main.js (one file for all pages)
├── images/        # Photos used on the site
├── Assets/        # CV PDF
└── README.md
```

---

## How to Run

1. Download the project folder
2. Open any `.html` file in your browser
3. Use the nav bar to move between pages

No installs, no setup. It just works.

> Google Fonts only load with an internet connection. The CV download needs the PDF to be inside the `Assets/` folder.

---

## Tech Used

- Google Fonts (Beau Rivage, Italiana, Kaisei HarunoUmi, Lato, Javanese Text)
